# Development Guidelines

This document outlines the local development setup and workflow for this repository.

## Prerequisites
- Git (latest stable version)
- Configuration files matching local environment variables

## Local Setup
1. Clone the repository to your local machine.
2. Ensure all environment dependencies are properly mapped.
3. Verify local configurations before executing project scripts.

## Git Workflow
- Always pull the latest changes before starting work.
- Use descriptive, imperative commit messages.
- Ensure the repository remains clean of temporary build files.
